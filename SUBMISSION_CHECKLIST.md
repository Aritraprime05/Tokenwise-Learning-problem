# Kalvium Submission Checklist

## Official requirements (from the supplied 3-page guide)
- [ ] Select exactly one listed topic: Tokenization and Context Window Management.
- [ ] Provide an interactive teaching artifact.
- [ ] Design the complete learning experience for 45 minutes.
- [ ] Explain concepts in simple, structured language.
- [ ] Demonstrate real-world scenarios.
- [ ] Include interactive experimentation.
- [ ] Include at least one hands-on activity, practical challenge or knowledge check.
- [ ] Explain real-world AI application.
- [ ] Submit either a public GitHub repository link or a ZIP with project files and access instructions.
- [ ] Submit an explanation video covering topic choice, teaching breakdown, underlying logic, interactivity, student use and real-world relevance.
- [ ] Verify all code examples and implementations are tested.
- [ ] Ensure you can personally explain the code and design decisions.
- [ ] Review the final submission carefully: the submission form can only be submitted once.

## Project quality checks
- [ ] Install dependencies in a clean Python 3.10+ environment.
- [ ] Run `pytest -q` and record the result.
- [ ] Run `streamlit run app.py`.
- [ ] Test empty input, long text, punctuation, numbers, Unicode and emoji.
- [ ] Try all three challenges.
- [ ] Complete the final assessment.
- [ ] Capture real screenshots and add them to `screenshots/`.
- [ ] Record and review the explanation video (5–7 minutes).
- [ ] Remove any local secrets or virtual environment from the ZIP.
- [ ] Optionally push the same project to a public GitHub repository.
